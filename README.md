一个关于人为什么向前走的游戏。

## 关于这个游戏

世界里有一种鹿，它一直向上攀登楼梯。

没有人知道楼梯通向哪里。

玩家跟着它走，或不走。  
世界随玩家的选择，慢慢染上颜色。

---

## 八个 Force

| Force | 核心问题 |
|-------|---------|
| **Seeking（追寻）** | 为什么人愿意一直向前。 |
| **Identity（认同）** | 方向一定只有一种吗？ |
| **Connection（连接）** | 有些关系，不需要结果。 |
| **Trace（留痕）** | 人与人从来不是交换。 |
| **Order（秩序）** | 为什么文明总想定义一切。 |
| **Creation（创造）** | 创造会不会反过来塑造创造者。 |
| **Constants（恒常）** | 有些规律，从来不会因为任何人而改变。 |
| **Variables（变数）** | 人生总会有一些变化，在毫无征兆的时候改变一切。 |

## 运行方式

> 本项目使用 Git LFS 管理大文件，clone 前需先安装 Git LFS。

```bash
git lfs install
git clone https://github.com/你的用户名/coloring.git
```

1. 安装 [Godot 4](https://godotengine.org/)
2. 用 Godot 4 打开项目目录
3. 运行 `scenes/seeking_world.tscn`
