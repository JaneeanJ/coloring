# Coloring / 着色

> 世界尚未完成它的着色。

**一个关于人如何在经历中逐渐成为自己的探索型叙事游戏。**

> 状态：粗略完成 · 精细调节中 · 尚未发布

# Origin

> **"我曾以为，人生会沿着某条既定的轨迹，走向那个曾经期待的终点。"**

但真正开始行走后，才发现，世界总会留下一些未曾写下的篇章。

一次出游中，我遇见了一件像画卷一样的衣服。

五彩斑斓的纹理，如同山川与时间留下的痕迹。

衣服如此，人生又何尝不是如此。

于是，《着色》诞生了。

关于那些相遇、离别，以及留下的颜色。

**世界仍在继续。**

**而着色，也还没有结束。**

# Gameplay

《着色》是一款以探索与叙事为核心的第三人称体验游戏。

玩家将在一个由象征构成的世界中探索，遇见八个抽象的 Force。

玩家可以通过探索与互动，与这些意向产生联系，并获得对应的装饰。

最终，所有经历都会汇聚成一件独属于玩家的衣裳。

> 人不是一开始就拥有完整的颜色。

> 我们是在经历中，慢慢成为自己的。

------

# Eight Forces

八个 Force 是游戏中的八种相遇，沿着自己 → 他人 → 文明 → 秩序四个维度展开，每一个都以一个具体的意向讨论人与世界的一种关系。

| 维度 | Force | 意向 | 主题 |
|------|-------|------|------|
| 自己 | **Seeking（追寻）** | 爬楼梯的鹿 | 为什么人愿意一直向前。 |
| 自己 | **Identity（认同）** | 倒着长的人 | 方向一定只有一种吗？ |
| 他人 | **Connection（连接）** | 梦中的拼图 | 人与人之间形成的东西，值不值得被留住、被放手、还是被分开保存。 |
| 他人 | **Eros（爱欲）** | 酒海 | 人在爱欲面前，会选择停靠、追寻、沉醉，还是重新飞翔。 |
| 文明 | **Order（秩序）** | 漂浮的门牌 | 为什么文明总想定义一切。 |
| 文明 | **Creation（创造）** | 四首歌，四幅画 | 创造会不会反过来塑造创造者。 |
| 秩序 | **Constants（恒常）** | 三台机器与一个病人 | 有些结局，不会因为足够努力而改变。 |
| 秩序 | **Variables（变数）** | 薄片 | 无常不会停止，人的生活也不会因此停止。 |

→ [每个 Force 的详细介绍](FORCES.md)

# How to Play

> 本项目使用 Git LFS 管理大文件，clone 前请先安装 Git LFS。


使用 **Godot 4** 打开项目，运行主场景：

```
scenes/seeking_world.tscn
```
